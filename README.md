# TRUST


## Платформа доверия Казахстана

TRUST — это единая платформа проверенных специалистов, компаний, магазинов, недвижимости, автомобилей, рекламных площадок и обучения.

---

## Основные категории

- 👨‍🔧 Услуги
- 🛍️ Маркет
- 📢 Реклама
- 🚗 Автомобили
- 🏠 Недвижимость
- 🎓 Обучение
- 💼 Работа
- 🏢 Компании

---

## Главная идея

Не объявления.

А проверенные профили.

Каждый пользователь проходит модерацию.

Каждый профиль получает статус TRUST VERIFIED.

🚧 Проект находится в активной разработке.
