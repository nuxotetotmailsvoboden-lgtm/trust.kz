# TRUST Architecture

## Основной принцип

Один пользователь.

↓

Один профиль.

↓

Много направлений.

Например:

- услуги
- товары
- мебель
- автомобили
- недвижимость
- обучение
- реклама

Все работают через единое ядро.

---

## TRUST VERIFIED

Проверяется:

- личность
- контакты
- документы
- деятельность

Документы видит только администрация.

Пользователи видят только статус проверки.

---

## TRUST SCORE

Будет рассчитываться на основе:

- документов
- отзывов
- времени работы
- активности
- жалоб
